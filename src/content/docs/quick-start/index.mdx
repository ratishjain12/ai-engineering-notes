Every note here comes with code you can run. The repo holds the site, the runnable examples for each topic, and the capstone project we build up to.

## 1. Star the repo <a class="cta" href="https://github.com/ratishjain12/ai-engineering-notes">★ Star</a>

Starring helps others find the repo, and you'll see new examples as they land.

## 2. Fork it <a class="cta" href="https://github.com/ratishjain12/ai-engineering-notes/fork">Fork</a>

Get your own copy to experiment in freely, and keep pulling updates from the original.

## 3. Clone your fork

```bash
git clone https://github.com/<your-username>/ai-engineering-notes.git
cd ai-engineering-notes
```

Keep up with new posts and examples by adding the original repo as `upstream`:

```bash
git remote add upstream https://github.com/ratishjain12/ai-engineering-notes.git
git pull upstream main
```

## What's inside

- `src/content/docs/` holds the notes you're reading.
- `examples/` holds runnable code for each topic, such as `examples/agents/agent-loop`. Each example has its own README with run instructions.
- The capstone project will live in the same repo and use what the notes cover.
